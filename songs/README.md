# 示例工程

## 短视频 BGM（原创，可商用）

- 126 BPM · Am–F–C–G 四和弦循环 · 8 小节 ×2
- 主旋律：钟琴（八分/四分音符，第 5 小节上高八度做 hook）
- 铺底：弦乐长音
- 鼓：四踩底鼓 + 2/4 拍 clap + 反拍开镲 + 八分闭镲
- 低音：自动跟和弦根音
- 文件：`short-video-bgm.json`

## 茉莉花（江苏民歌，公有领域）

- C 大调 · 84 BPM · 12 小节
- 旋律：钢琴·采样（Salamander，CC-BY 3.0）
- 和弦：C / G / Am / C
- 文件：`jasmine.json`

---

**怎么打开**：页面展开「工程数据」→「导入工程」→ 选对应的 json。

版本

打开页面时如果还是旧界面，说明浏览器缓存了旧文件： 按 Ctrl+Shift+R 强制刷新，或在开发者工具的 Application → Service Workers 里点 Unregister 再刷新。

快捷键 先记这几个，效率翻倍

  • 空格 播放 / 停止 · Esc 停止播放
  • R 开始 / 停止录音 · N 新建轨道
  • Ctrl+Z 撤销 · Ctrl+Shift+Z 重做
  • Ctrl+C 复制选区 · Ctrl+V 进入粘贴模式
  • E 导出 WAV · + 时间轴 +20 小节
  • Shift 拖拽 = 框选（手机上点「选择」按钮）
  • Alt 拖方块 = 改力度；Alt 点目标格 = 移调粘贴

在输入框、下拉框里打字时快捷键不生效，不会抢你的按键。

界面怎么用

  • 录音 / 导入：点「开始录音」哼一段再点「停止」；或点「导入音频」选本地文件。 结束后自动识别音高、清洗量化，然后循环播放。
  • 轨道 = 乐器：每条轨道自带音阶网格，点格子加音、点方块删音。 轨头那个下拉既是轨道名也是音色——换成「钟琴」，这条轨就叫钟琴了。
  • 复制一段旋律：按住 Shift 在格子上拖一个框 → Ctrl+C（或点「复制」）→ 点目标格子粘贴。默认音高原样不变、轨道音阶自动扩展到装得下； 按住 Alt 再点目标格子，则整段移调，让最低音落在你点的那一行。
  • 改音符：直接拖动方块改位置和音高，拖右边缘改长度；Alt + 上下拖改力度；框选多个后拖动会一起移动。 改错了按 Ctrl+Z 撤销，Ctrl+Shift+Z 重做。
  • 工程自动保存：每次改动都会存进这台浏览器，关掉再打开自动恢复。 想换机器或备份，展开底部「工程数据」导出 JSON，另一台再导入。
  • 加轨道：左上「＋新轨道」，新轨和第一条一样自带音阶，可以直接画。
  • 调宽窄：拖动左侧音阶栏的右边缘即可，宽度会记在浏览器里。
  • 鼓点：下方 6 条泳道（底鼓/军鼓/闭镲/开镲/拍手/通鼓），点一下加一个，同格再点删掉。
  • 时间轴：默认 50 小节，点「＋20 小节」加长；拖 BPM 是整体变速，音符位置不会重排。
  • 从中间听：点上方刻度尺的任意位置，播放头跳过去，再按播放就从那儿开始。
  • 节拍器：勾上后播放和录音都会打拍子；录音前会先给 4 拍预备，跟着数就行。
  • 测速：录完点 BPM 旁边的「测速」，从音频里估出速度并写进滑块（60–180 之间）。
  • 调性 / 吸附：点「检测调性」看当前轨大概是哪个调；跑调的点「吸附到调」， 会把不在音阶上的音就近拉回来（保持八度）。
  • 导出 MIDI：右上「MIDI」导标准 .mid 文件，直接拖进 FL Studio / Logic / Cubase 都能用。
  • 力度：框选一段后，时间轴下方会出现「力度」滑杆，可以整体调；单颗音符用 Alt 上下拖。 力度只影响音量轻重，不改音高。
  • 混音：时间轴下方每条轨/低音/鼓各有一条通道条——推子（dB）、声像、 低/中/高三段 EQ、混响发送量，以及 M（静音）/ S（独奏）。改完实时生效，导出 WAV 时同样生效。
  • 导出：右上角「下载 WAV」，可选循环 1 / 2 / 4 遍；「MIDI」导出标准 .mid。
  • 缩放：时间轴标题行的「− 100% +」调网格宽度（50%–200%），50 小节也不会滚到崩溃；下次打开还记得。
  • 分享：点右上「分享」把整个工程压进链接复制到剪贴板，别人打开链接就直接看到你的编曲。
  • 和弦：点「生成和弦」，按小节推断三和弦并在时间轴上方显示；勾着「低音」时，低音会改成跟和弦根音走。
  • 装成 App：用 http(s) 打开时，浏览器地址栏会出现"安装"图标； 装好后从桌面/开始菜单启动，断网也能用（应用外壳已缓存，Tone.js 自带）。
  • 手机上：左侧栏会变成顶部横条，工具条可以左右滑动。想框选就点工具条里的「选择」， 然后用手指在格子上拖出选框——选框出现后，下方会有「删除选区」「±12 移调」和力度滑杆。

出问题怎么办

  • 必须用 http(s) 打开：麦克风只在「安全上下文」可用。本机起服务器： python -m http.server 8000 或 npx serve，访问 http://localhost:8000。直接双击 file:// 多数浏览器会拒绝授权。
  • CDN 加载失败：页面会自动换源（模块 esm.sh → jsDelivr；模型 jsDelivr → unpkg）。 都被墙时引擎自动退回内置 YIN，流程照样跑通（结果里会注明用的是备用引擎）。
  • 有点慢：Basic Pitch 按 2 秒窗逐段推理，进度条是真实进度。
  • 导入的音频没反应：浏览器只解码得了它支持的格式（mp3 / wav / ogg / m4a）。 整首带伴奏的歌只会被提成稀疏的旋律骨架——Basic Pitch 的定位是「一次一种乐器」。
  • 点了格子没反应：先看底部状态栏有没有「加了 X（第 N 格）」——有就是渲染问题， 没有说明点击没命中，可能是没点在泳道区域内。

替代方案

  • 要更准或离线：本机跑 Python 版 basic-pitch，前端只上传音频换 MIDI。
  • 只要单音高：pitchy / CREPE-tiny，体积更小。
  • 要实时「边唱边出声」：换成 AudioWorklet + 逐帧检测，本原型「录完再处理」的结构需要重写。
  • 想要更像真乐器：必须用采样音色（Tone.Sampler），但那会引入第三方采样版权， 和本工具「可商用」的定位冲突，所以目前只做合成器音色。
